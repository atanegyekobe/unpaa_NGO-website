3. **Perfect for NGOs**

5. **Easy image & video management**

### **What is it?**
Think of it as a **WordPress admin panel** for your React website, but:
- Faster
- More modern
- More flexible
- Better for React

### **Example Workflow:**
1. Open Strapi admin panel (like WordPress)
2. Click "Create New Post"
3. Write your title, content
4. Upload images/videos
5. Click "Publish"
6. **Post automatically appears on your website!**

## ⚡ **Quick Setup (30 minutes)**

### **Step 1: Install Strapi**
```bash
npx create-strapi-app newda-cms --quickstart
cd newda-cms
npm run develop
```

### **Step 2: Create Admin Account**
Opens automatically in browser

### **Step 3: Create "Blog Post" Content Type**
In admin panel:
- Click "Content-Type Builder"
- Add fields: Title, Content, Image, Date, Category, etc.

### **Step 4: Add Your First Post**
- Go to "Content Manager"
- Click "Create new entry"
- Write your post
- Upload images
- Publish!

### **Step 5: Connect to Your Website**
Simple API call in your React code (I'll help with this!)
