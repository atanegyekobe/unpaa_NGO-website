# 🔗 Website URLs Reference

## All Available Pages

When running locally (`npm run dev`), your website will be available at these URLs:

### Main Pages

| Page | URL | Description |
|------|-----|-------------|
| **Home** | `http://localhost:5173/` | Landing page with hero and overview |
| **About** | `http://localhost:5173/about` | Mission, vision, values, and team |
| **Programs** | `http://localhost:5173/programs` | Program showcase and process |
| **Impact** | `http://localhost:5173/impact` | Statistics, stories, and reports |
| **Get Involved** | `http://localhost:5173/get-involved` | Ways to support the organization |
| **Contact** | `http://localhost:5173/contact` | Contact form and FAQ |

## When Deployed (Production)

Replace `localhost:5173` with your domain:

| Page | URL Example |
|------|-------------|
| **Home** | `https://newda.org/` |
| **About** | `https://newda.org/about` |
| **Programs** | `https://newda.org/programs` |
| **Impact** | `https://newda.org/impact` |
| **Get Involved** | `https://newda.org/get-involved` |
| **Contact** | `https://newda.org/contact` |

## URL Features

✅ **Shareable** - Send direct links to specific pages
✅ **Bookmarkable** - Users can bookmark individual pages
✅ **SEO Friendly** - Each page has its own URL for search engines
✅ **Browser History** - Back/forward buttons work correctly
✅ **Professional** - Standard website behavior

## Common Use Cases

### Sharing on Social Media
Share specific pages:
- "Learn about us: newda.org/about"
- "See our impact: newda.org/impact"
- "Get involved: newda.org/get-involved"

### Email Campaigns
Link to specific pages in emails:
- "Donate here: newda.org/get-involved"
- "Contact us: newda.org/contact"

### Marketing Materials
Print materials can include:
- "Visit newda.org/programs to learn more"
- "See our impact at newda.org/impact"

---

**Note:** These URLs work with React Router's client-side routing, so the page never actually reloads - it's instant and smooth! 🚀
